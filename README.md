# Sistema de Cadastro de Usuários

Projeto desenvolvido em Java como parte dos meus estudos em Programação Orientada a Objetos (POO) e consumo de APIs.

## Funcionalidades

* Criar conta
* Login de usuário
* Listar usuários
* Atualizar senha
* Atualizar CEP
* Deletar conta
* Buscar endereço pelo CEP

## API

Uso da ViaCEP API para buscar automaticamente:

* Rua
* Cidade
* Estado

## Estrutura

* **Classes** → definição dos dados
* **Funções** → lógica do sistema
* **Main** → execução e interação com o usuário

## Observação

Este projeto faz parte do meu processo de aprendizado e está em constante evolução.
